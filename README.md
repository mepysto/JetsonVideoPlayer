# JetsonVideoPlayer

NVIDIA Jetson의 하드웨어 가속을 사용하는 GTK/GStreamer 영상 플레이어입니다.

지원 코덱은 현재 장치의 `nvv4l2decoder` 기능을 기준으로 판정하고 NVIDIA 하드웨어
디코더를 우선 사용합니다. 하드웨어 디코딩이 불가능한 코덱이나 프로파일만 H.265로
변환하며, 원본은 `unsupported_originals` 폴더에 보관합니다. 10-bit/HDR 입력은
Main10 10-bit로 보존합니다.

## UI 기능

- 폴더 로딩 시 하위 폴더를 계층형 트리(TreeView)로 구성 (폴더 클릭 시 펼치기/접기 토글, '전체 펼치기' / '전체 접기' 툴바, 현재 재생 영상 자동 강조 및 스크롤)
- 영상 재생 시 해당 영상의 모든 언어 자막 자동 로드 및 화면 동시 다중 표출 (기본값)
- 영상 속도 제어 (0.25x ~ 3.0x, scaletempo 오디오 피치 유지, UI 버튼 및 팝오버 메뉴, 키보드 단축키 지원)
- 재생/일시정지, 이전/다음 영상
- 10초 전/후 탐색과 클릭 가능한 진행바 (Shift 조합 시 30초 탐색)
- 화면 마우스 휠 스크롤로 10초 전/후 즉각 Seek 탐색
- 전체화면(Fullscreen) 모드에서도 마우스 조작 시 플로팅 컨트롤 바 자동 표시 (진행 바 탐색, 속도 조절, 자막, 볼륨) 및 2.5초 후 자동 숨김
- 속도 변경 및 탐색 시 직관적인 화면 중앙 상단 OSD(On-Screen Display) 알림
- 현재 시간/전체 재생 시간 표시
- 음량 조절 (일반 모드와 전체화면 모드 상호 동기화)
- 다중 자막(SMI, SRT, VTT, ASS 등) 자동 탐색 및 언어별 감지(한국어, 영어, 일본어, 중국어 등)
- 언어별 고대비 고유 색상 자동 차별화 (한국어: 화이트, 영어: 레몬 옐로우, 중국어/대만어: 시안 블루, 일본어: 네온 민트 등)
- 다중 자막 동시 표시(Dual/Multi Subtitles) 및 개수별 자동 컴팩트 크기 최적화 (화면 가림 방지)
- 자막 크기 실시간 조절 (60% ~ 160% 스케일, 팝오버 버튼 및 단축키 `[` / `]` 지원)
- 자막 싱크(Sync) 실시간 미세 조절 (0.1초 / 0.5초 단위 앞당김/늦춤, 단축키 `Z` / `X` / `,` / `.` 지원)
- 자막 선택 팝오버(Popover) 메뉴 및 실시간 다중 선택/해제
- 자막 켜기/끄기 토글 버튼 및 단축키
- 재생목록 열기/닫기와 모든 UI를 숨기는 영상 전용 전체화면
- 전체화면 시 마우스 커서 자동 숨김 (마우스 움직임 시 나타나고 2.5초 후 자동 숨김)
- 마우스 더블클릭으로 전체화면 전환 토글
- 영상 종료 시 다음 항목 자동 재생
- 실제 선택 디코더와 프레임 드롭 통계 로그

## 설치 (어디서든 실행하기)

프로젝트 디렉토리에서 설치 스크립트를 실행하면 `~/.local/bin`에 등록되어 터미널 어디서든 명령어로 바로 실행할 수 있습니다:

```bash
./install.sh
```

*(시스템 전체 설치를 원할 경우 `sudo ./install.sh --system`)*

제거하려면:
```bash
./uninstall.sh
```

## 실행

설치 후 터미널 어디서든 `jetson-player` (또는 `jetson_player`) 명령어로 실행할 수 있습니다:

```bash
# 디렉토리 내 모든 동영상(하위 폴더 포함) 연속 재생
jetson-player /path/to/video-directory

# 단일 동영상 파일 재생
jetson-player /path/to/video.mp4
```

Python 스크립트로 직접 실행할 수도 있습니다:
```bash
python3 jetson_player.py /path/to/video-directory
```

## 키보드 및 마우스 조작

| 키 / 마우스 | 동작 |
| --- | --- |
| `Space` | 재생/일시정지 |
| `Left` / `Right` | 10초 이전/다음 (Shift 누를 시 30초) |
| `J` / `L` | 10초 이전/다음 (유튜브 스타일) |
| `마우스 휠 스크롤` | 위: 10초 앞으로 / 아래: 10초 뒤로 Seek |
| `Up` / `Down` 또는 `D` / `A` | 재생 속도 빠르게 / 느리게 (+0.25x / -0.25x) |
| `>` / `<` (Shift+`.` / Shift+`,`) | 재생 속도 빠르게 / 느리게 |
| `R` | 재생 속도 기본값(1.0x) 복원 |
| `P` / `N` | 이전/다음 영상 |
| `S` | 자막 전체 켜기/끄기 (Subtitle ON/OFF) |
| `C` | 다중 자막 선택 및 크기/싱크 조절 메뉴 열기 (Caption Menu) |
| `[` / `]` | 자막 크기 축소 / 확대 (Font Size -10% / +10%) |
| `Z` / `X` | 자막 싱크 빠르게 / 느리게 (Sync -0.5s / +0.5s) |
| `,` / `.` | 자막 싱크 미세 조절 (Sync -0.1s / +0.1s) |
| `F` | 영상 전용 전체화면 전환 토글 |
| `마우스 더블클릭` | 전체화면 전환 토글 |
| `Esc` | 영상 전체화면 해제, 일반 화면에서는 종료 |
| `Q` | 종료 |
