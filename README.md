# JetsonVideoPlayer

NVIDIA Jetson의 하드웨어 가속(`nvv4l2decoder`)을 사용하는 고성능 GTK3/GStreamer 영상 플레이어입니다.

하드웨어 디코더를 우선 사용하여 초저지연·고효율 4K/H.265/H.264 재생을 지원하며, 하드웨어 디코딩이 지원되지 않는 특수 코덱은 안전한 소프트웨어 디코딩으로 부드럽게 재생합니다.

---

## 주요 기능 및 UX 특징

### 1. 스마트폰 웹 리모컨 (Web Remote Control)
- **Wi-Fi 무선 원격 제어**: 플레이어 실행 시 내장 초경량 백그라운드 웹 서버가 자동 구동됩니다 (`http://<Jetson-IP>:8888`).
- **모바일 웹 UI**: 같은 Wi-Fi에 연결된 스마트폰 브라우저로 접속하여 재생/일시정지, 10초 탐색, 진행바 탐색, 볼륨/부스트 조절, 자막 토글, 전체화면, 반복 모드, 재생목록 선택, 무손실 스크린샷 캡처를 편리하게 원격 조작할 수 있습니다.
- 상단 탑바의 `📱 리모컨` 버튼 클릭 시 접속 주소 확인 및 원클릭 클립보드 복사를 지원합니다.

### 2. A-B 구간 반복 (A-B Repeat) & 북마크 (Bookmarks)
- **A-B 구간 반복**: 단축키 `Shift+[`(A 지점) / `Shift+]`(B 지점)으로 원하는 학습/분석 구간을 설정하여 무한 반복 재생할 수 있습니다 (`\` 키로 해제).
- **북마크 타임스탬프 저장**: `B` 키로 중요 장면을 즉시 북마크하고, `Ctrl+B` 또는 상단 `🔖 북마크` 버튼을 눌러 목록에서 클릭 한 번으로 해당 위치로 즉시 점프합니다 (`~/.cache/jetson_video_player/bookmarks.json` 영구 저장).

### 3. 무손실 스크린샷 캡처 (Screenshot)
- **원본 해상도 무손실 캡처 (`Ctrl+S`)**: GStreamer 파이프라인에서 현재 프레임 버퍼를 직접 추출하여 무손실 PNG로 즉시 저장합니다 (`~/Pictures/JetsonVideoPlayer/Screenshot_YYYYMMDD_HHMMSS.png`).
- 상단바 `📸 캡처` 버튼 또는 마우스 우클릭 메뉴를 통해서도 마우스만으로 간편하게 캡처 가능합니다.

### 4. Jetson 하드웨어 & 미디어 모니터링 HUD (`I`)
- **Jetson SoC 실시간 상태 표시**:
  - 하드웨어 디코더(`nvv4l2decoder` vs SW), 해상도, 프레임 드롭률, 오디오/자막 트랙 상태.
  - **SoC 온도(CPU / GPU °C)**, **실시간 GPU 로드(%)**, **시스템 RAM 점유율**, **웹 리모컨 접속 URL**을 반투명 오버레이 HUD로 실시간 표시합니다.

### 5. 오디오 부스트 (최대 200%) & AV 싱크 미세 조절
- **오디오 볼륨 부스트 (최대 200%)**: 기본 100% 음량보다 더 크게 증폭하여 소리가 작게 녹음된 영상이나 야외 환경에서도 또렷하게 청취 가능합니다 (`🔊 볼륨: 140% (부스트)`).
- **오디오/비디오(AV) 싱크 실시간 보정**: 블루투스 스피커/이어폰 사용 시 발생하는 음성 밀림 현상을 `Shift+Z`(-50ms 당김) / `Shift+X`(+50ms 늦춤) / `Shift+C`(0ms 초기화)로 실시간 미세 보정합니다.

### 6. 최근 재생 목록 (History)
- 상단 탑바의 `🕒 최근` 버튼을 클릭하면 최근 시청한 동영상 파일 및 폴더 목록(최대 15개)을 확인하고 원클릭으로 바로 이어서 재생할 수 있습니다 (`~/.cache/jetson_video_player/history.json`).

### 7. 직관적인 마우스 인터랙션 & 완벽한 휠 격리
- **마우스 싱글 클릭**: 재생 / 일시정지 (더블클릭 디바운스 분리).
- **마우스 더블 클릭**: 영상 전용 전체화면(Borderless Fullscreen) 토글.
- **마우스 휠 스크롤 Seek**: 마우스 휠 위/아래로 10초 앞/뒤 빠른 탐색.
  - *플레이리스트 패널이나 컨트롤 바에서의 스크롤과 물리적으로 격리되어 목록 탐색 시 비디오 탐색이 오작동하지 않습니다.*
- **우클릭 컨텍스트 메뉴**: 마우스 우클릭으로 재생 제어, 속도, 구간 반복, AV 싱크, 자막, 오디오 트랙, 북마크, 스크린샷, 웹 리모컨 등 모든 기능에 빠른 접근.

### 8. 스마트 다중 자막 & 디바운스 최적화
- **자동 언어 감지 및 고대비 색상**: 한국어(화이트), 영어(레몬 옐로우), 중국어(시안), 일본어(민트) 등 자동 분리 표출.
- **스마트 기본 표시**: 다중 자막 감지 시 화면 가림을 방지하기 위해 기본 1개(한국어 우선)만 자동 활성화.
- **싱크 & 크기 조절 디바운스(150ms)**: 단축키 연타 시 화면 깜빡임과 파이프라인 정체 현상을 100% 방지.

### 9. 고도화된 재생목록 & 탐색
- **실시간 검색 필터**: 사이드바 상단 검색창에 키워드 입력 시 실시간 트리 필터링 (엔터 시 첫 검색 결과 즉시 재생).
- **계층형 트리 구조**: 하위 폴더별 계층 트리 표시, 폴더 전체 펼치기/접기, 현재 재생 항목 자동 강조 및 스크롤.
- **다양한 재생 모드**: 전체 반복(`🔁`) ➔ 1곡 반복(`🔂`) ➔ 순차 후 정지(`➡️`) ➔ 셔플/무작위(`🔀`) 순환 지원 (`Shift+R`).
- **자동 이어보기 (Resume Playback)**: 5초 이상 시청한 지점을 자동 저장하여 다음 번 재생 시 마지막 위치부터 이어 재생.

## 설치 및 실행

### 어디서든 실행하기 (CLI 등록)
프로젝트 디렉토리에서 설치 스크립트를 실행하면 `~/.local/bin`에 등록되어 터미널 어디서든 명령어로 바로 실행할 수 있습니다:

```bash
./install.sh
```

*(시스템 전체 설치: `sudo ./install.sh --system` / 제거: `./uninstall.sh`)*

### 실행 방법
```bash
# 1. 인자 없이 실행 (대기 화면에서 파일 선택 또는 드래그 앤 드롭)
jetson-player

# 2. 특정 동영상 파일 직접 재생
jetson-player /path/to/video.mp4

# 3. 디렉토리 내 모든 동영상(하위 폴더 포함) 재생목록으로 재생
jetson-player /path/to/video-directory
```

## 키보드 및 마우스 단축키 일람

단축키는 플레이어 실행 중 `F1` 키를 눌러 안내 대화상자로 언제든지 확인할 수 있습니다.

### 재생 및 탐색
| 조작 | 기능 |
| --- | --- |
| `Space` / `마우스 좌클릭` | 재생 / 일시정지 (화면 클릭) |
| `Left` / `Right` | 10초 이전 / 10초 다음 탐색 |
| `Shift + Left` / `Shift + Right` | 30초 이전 / 30초 다음 탐색 |
| `J` / `L` | 10초 이전 / 10초 다음 탐색 (YouTube 스타일) |
| `마우스 휠 스크롤` | 영상 영역에서 위(10초 앞) / 아래(10초 뒤) Seek |
| `P` / `N` | 이전 영상 / 다음 영상 재생 |
| `Up` / `Down` 또는 `D` / `A` | 재생 속도 빠르게 / 느리게 (+0.25x / -0.25x) |
| `>` / `<` (`Shift+.` / `Shift+,`) | 재생 속도 빠르게 / 느리게 |
| `R` | 재생 속도 기본값(1.0x) 복원 |
| `Shift + R` | 재생 모드 순환 (전체반복 ➔ 한곡반복 ➔ 순차정지 ➔ 셔플) |

### 구간 반복 & 북마크 & 캡처
| 조작 | 기능 |
| --- | --- |
| `Shift + [` | A-B 구간 반복 시작점 (A) 설정 |
| `Shift + ]` | A-B 구간 반복 종료점 (B) 설정 및 루프 활성화 |
| `\` (백슬래시) | A-B 구간 반복 해제 |
| `B` | 현재 재생 위치 북마크 추가 |
| `Ctrl + B` | 북마크 목록 팝오버 열기 (클릭 시 점프 / 삭제) |
| `Ctrl + S` | 현재 프레임 원본 무손실 스크린샷 저장 |

### 화면 및 오디오
| 조작 | 기능 |
| --- | --- |
| `0` / `9` (또는 `Shift+Up` / `Shift+Down`) | 볼륨 5% 올리기 / 내리기 (최대 200% 부스트) |
| `M` | 음소거 (Mute) 토글 |
| `Shift + Z` / `Shift + X` | 오디오(AV) 싱크 50ms 앞당김 / 늦춤 |
| `Shift + C` | 오디오(AV) 싱크 0ms 초기화 |
| `Shift + A` | 오디오(음성) 트랙 전환 (다중 더빙 영상) |
| `F` / `마우스 더블클릭` | 영상 전용 전체화면 토글 |
| `T` | 창 항상 위에 표시 토글 (Always on Top) |
| `I` | Jetson 하드웨어 & 미디어 통계 HUD 토글 |
| `마우스 우클릭` | 빠른 조작 컨텍스트 메뉴 표시 |

### 자막 제어
| 조작 | 기능 |
| --- | --- |
| `S` | 자막 전체 표시 켜기 / 끄기 |
| `C` | 자막 선택 및 세부 설정 팝오버 열기 |
| `[` / `]` | 자막 글자 크기 축소 / 확대 (-10% / +10%) |
| `Z` / `X` | 자막 싱크 빠르게 / 느리게 (-0.5s / +0.5s) |
| `,` / `.` | 자막 싱크 미세 조절 (-0.1s / +0.1s) |

### 파일 및 일반
| 조작 | 기능 |
| --- | --- |
| `Ctrl + O` | 동영상 파일 열기 다이얼로그 |
| `Ctrl + Shift + O` | 동영상 폴더 열기 다이얼로그 |
| `F1` | 단축키 및 도움말 다이얼로그 표시 |
| `Esc` | 전체화면 해제 (일반 창 모드에서는 종료) |
| `Q` | 플레이어 종료 |
